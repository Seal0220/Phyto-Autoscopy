# 分析實作說明

正式分析方法只包含：

- `rotating`：俯視、側視與同一 Round 的全部有效旋臂視角，共同建立三維模型、尖端標記與跨 Round 軌跡。
- `fixed`：使用俯視與側視影像建立尖端標記與軌跡，不宣稱輸出完整環繞模型。

分析輸入以 `Record → Mode → Round → Snapshot → Camera` 為唯一資料階層。新建分析會固化來源清單、相機內參、實測雙鏡頭基線與俯視鏡頭高度、無標記姿態門檻、模型後端與執行環境；原始捕捉影像保持唯讀。舊分析的 ArUco 快照仍可讀取。

所有影像先依實體相機內參完成去畸變。新分析以雙鏡頭特徵建立固定姿態與公制尺度，以三維特徵／PnP 建立旋臂姿態，再進行多視角重建、植物遮罩與尖端標記分析。二維分析座標一律使用去畸變座標。無足夠共同特徵或幾何退化時明確失敗，不推測未量測的尺度。

舊的人工影格偏移、全域影格範圍、ROI、人工植物基部像素、MOG2 時序背景與舊 Analysis Run 讀取流程均不屬於正式分析介面。

模型後端透過統一 Registry 執行。單一 Round 失敗時保留其他已完成 Round 與診斷資訊；取消、重試與重設都以 Round 產物為邊界。

論文中的固定雙鏡頭基準採用時序背景模型（MOG2）尋找尖端；目前正式流程依 GOAL-05 使用逐張植物遮罩與多視角候選，不是逐像素重現論文演算法。因此論文報告的偵測率與定位精度不能直接宣稱為本系統的實測結果。`rotating` 的逐輪 3DGS 亦屬本專案的延伸方法，必須以實際 Record 與 GPU 執行結果分別驗證。

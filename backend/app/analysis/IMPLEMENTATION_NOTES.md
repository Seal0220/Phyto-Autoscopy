# 分析實作說明

正式分析方法只包含：

- `rotating`：俯視、側視與同一 Round 的全部有效旋臂視角，共同建立三維模型、尖端標記與跨 Round 軌跡。
- `fixed`：使用俯視與側視影像建立尖端標記與軌跡，不宣稱輸出完整環繞模型。

分析輸入以 `Record → Mode → Round → Snapshot → Camera` 為唯一資料階層。新建分析會固化來源清單、相機內參、實測雙鏡頭基線與俯視鏡頭高度、無標記姿態門檻、模型後端與執行環境；原始捕捉影像保持唯讀。舊分析的 ArUco 快照仍可讀取。

所有影像以輪為單位依實體相機內參完成去畸變。旋臂分析將該輪所有俯視、側視與旋臂影像提交同一個 COLMAP SfM，以成功註冊的原始影像姿態建立一次 3DGS 參考模型。模型與尖端量測分開：後續公制相機配準及人工尖端修正只更新量測資料，不重訓、裁切或變形模型。二維標記一律使用去畸變座標；沒有可用公制姿態時不產生推測的毫米座標。

舊的人工影格偏移、全域影格範圍、ROI、人工植物基部像素、MOG2 時序背景與舊 Analysis Run 讀取流程均不屬於正式分析介面。

模型後端透過統一 Registry 執行。單一 Round 失敗時保留其他已完成 Round 與診斷資訊；取消、重試與重設都以 Round 產物為邊界。

論文中的固定雙鏡頭基準採用時序背景模型（MOG2）尋找尖端；目前正式流程依 GOAL-05 使用逐張植物遮罩與多視角候選，不是逐像素重現論文演算法。因此論文報告的偵測率與定位精度不能直接宣稱為本系統的實測結果。`rotating` 的逐輪 3DGS 亦屬本專案的延伸方法，必須以實際 Record 與 GPU 執行結果分別驗證。

旋臂初始影像對依校正後影像估計的三角化角度與幾何內點數選擇，不只挑配對數最多的相鄰影像。馬達角度只限制候選範圍、排除明顯不合理的兩視角解，不設定影像重建姿態。OpenCV 內參轉入 COLMAP 時，主點座標加 0.5 px；回到影像標記與 3DGS 訓練時仍使用原始 OpenCV 內參。

參考模型使用 COLMAP 的初始共同求解，不再套用後續自訂姿態精修、固定鏡頭重定位或第二次共同訓練；診斷模組仍可獨立使用。參考模型政策為 `immutable_per_round_v1`，品質記錄輸入鏡頭數、實際註冊視角與未註冊視角。尺度／軌道配準失敗時，已完成模型仍保留為相對座標參考。

姿態品質區分影像軌道的內部一致性、馬達校正的保留樣本 RMSE／絕對誤差第 95 百分位，以及三鏡頭實際註冊狀態。`absolute_accuracy_verified` 在沒有獨立真值時維持 false。輸入三鏡頭不保證全部視角都能註冊；未註冊影像不以猜測姿態加入訓練。角度低於 1° 的內部指標不能直接宣稱尖端已達論文粗估的約 5 mm 定位精度。

人工模型對齊失敗時仍檢查俯視與側視兩個鏡頭，保存每組候選的重投影誤差、正深度與需檢查編號。未通過的候選不當作已驗證內點，草稿保持可編輯，不啟動分析。前端將「3/5 組」這類數量改用全形斜線顯示，以免錯誤訊息的檔案路徑過濾遮住幾何原因；實際格式錯誤仍以 HTTP 422 處理。

每輪依序完成影像處理、參考模型、尖端嘗試及全域圖表發布，再開始下一輪。相機對齊不足記為 `alignment_pending`，其他前處理失敗記為 `failed`；尖端缺失或身份未確認保留缺值，繼續下一輪，不沿用前一輪或跨失敗輪次插值。模型及配準保存在該輪自己的 `pose_debug` 目錄，不使用另一輪的模型座標重建。人工相機對齊仍可另行補正量測姿態；已完成參考模型保持不變。程式重啟不自動啟動工作。

每輪參考模型獨立建立。`round.00` 缺少旋臂軌道時，可使用已驗證的共用實體固定鏡頭參照進行尖端量測；完整旋臂輪次仍使用自己的模型與配準。

跳過輪次保存政策版本，不在每次恢復時無限重試。另一個旋臂輪次完成公制配準不會自動拿其座標處理已跳過的輪次。使用者可在各輪手動標記尖端或明確重試本輪。

尖端分析版本 5 將一般幾何／骨架端點視為候選，不把低重投影誤差等同於已找到植物生長尖端。自動確認還要求尖端身份明確、至少兩個不同鏡頭支持及原有信心、前景與重投影檢查；目前的一般端點偵測器未提供生長尖端身份，因此這類候選保留為待人工確認。參考模型不再提供尖端吸附或骨架修正。

各輪結果提供相同的「標記尖端／修改尖端」影像操作，已找到與缺失的尖端均可修改。使用者只需在同一組擷取的至少兩個鏡頭點選同一尖端並儲存，不需模型配對點或另填原因。保存原始點選座標；所有點須位於影像內、形成有效正深度三維點且通過逐點重投影門檻。

訓練或自動分析期間可保存尖端修正，立即更新目前採用的尖端、CSV 與全域軌跡。人工及自動圖表發布共用鎖，最新人工修正優先；進度通知帶 `results_revision`，前端讀取最新結果，不改變在途工作的階段或進度。沒有公制姿態時保存 `pending_alignment` 的二維標記並保留圖表缺值，姿態可用後以原始點選重新計算；不重訓模型。模型上的毫米尖端只以逆相似變換映射到保留的模型座標，無轉換時不顯示錯位的三維標記。

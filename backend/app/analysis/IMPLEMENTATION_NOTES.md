# 分析實作說明

正式分析方法只包含：

- `round_multiview`：俯視、側視與同一 Round 的全部有效旋臂視角，共同建立三維模型、尖端標記與跨 Round 軌跡。
- `top_side_tip_only`：使用俯視與側視影像建立尖端標記與軌跡，不宣稱輸出完整環繞模型。

分析輸入以 `Record → Mode → Round → Snapshot → Camera` 為唯一資料階層。建立分析時會固化來源清單、相機內參、ArUco 世界座標配置、模型後端與執行環境；原始捕捉影像保持唯讀。

所有影像先依實體相機內參完成去畸變，再進行 ArUco 姿態估算、多視角重建、植物遮罩與尖端標記分析。二維分析座標一律使用去畸變座標。

舊的人工影格偏移、全域影格範圍、ROI、人工植物基部像素、MOG2 時序背景與舊 Analysis Run 讀取流程均不屬於正式分析介面。

模型後端透過統一 Registry 執行。單一 Round 失敗時保留其他已完成 Round 與診斷資訊；取消、重試與重設都以 Round 產物為邊界。
